GFS v4.0.0 正式版

> 2026-09-19 重新打包：修复部署包内嵌前端过期与数据库初始化失败问题，并纳入 SFTP 随机读、SMB 挂载等多项修复。请务必下载 2026-09-19 之后的安装包。

## 新功能

- **WebDAV 支持 HTTP Range 分片下载**（秒开 / 拖进度条 / 断点续播）
- **SFTP 支持真随机读**：读取通道基于 `openRangeStream` 按偏移精确定位，VLC / PotPlayer / mpv 走 `sftp://` 或 sshfs 挂载播放大视频时拖进度条秒级响应（实测单次 seek 约 10ms，明文与落盘加密表现一致）
- **SMB 接入挂载式存储**：SMB 共享目录自动镜像为网盘目录树（挂载能力位驱动），每 5 分钟定时同步，文件列表所见即共享内容
- 一键复制直链
- 批量 ZIP 下载
- 站内搜索体验增强

## 问题修复

- **修复部署后前端显示为旧版**：发行包部署后浏览器实际加载的是 jar 内嵌前端，而非包内 `frontend/` 目录；已同步最新构建产物并在打包脚本中增加内嵌前端一致性校验，杜绝旧包
- **修复首次部署数据库初始化失败**：旧 `init.sql` 缺少 `service_settings` 等新表、含已废弃表和过期种子数据，导致后端启动即失败；已用当前代码实体结构重建干净基线（22 张表）
- **修复 SMB 浏览子目录认证失败**：插件实例长期缓存但每次操作新建会话不销毁，NAS 会话堆积到上限后拒绝认证；改为常驻连接/会话/共享，失效自动整链重建
- **修复启动 banner 字样错误**（FES → GFS）

## 移除

- 移除未使用的 fs-notify 邮件模块及 `spring.mail` 配置（全工程无调用方，减少依赖）

## 文档

- 文档体系重构为编号式中文系统设计文档（`doc/00` ~ `doc/13`）：总体架构、前端、认证、数据模型、上传链路、下载预览、分享直链、回收站、存储插件、存储配置、对外服务、日志审计、安全基建
- 补充 SFTP 真随机读设计与挂载式存储能力位说明
