# GFS 系统设计文档

一套用于学习 GFS（现代化文件管理网盘系统）架构设计与技术选型的**中文系统设计文档**。

> 从零读懂：分层架构、模块职责、核心链路与关键代码设计动机。文档统一使用 `NN-中文标题.md` 命名，按编号顺序组织。
