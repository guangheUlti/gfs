# GFS v5.0.1 发布说明

`gfs-5.0.1-windows-x64.zip`（自带 JDK 21、MySQL 8.4、Redis，免安装部署）

## 主要变更

### 界面优化

- **前端响应式布局**：移除左侧菜单栏的收起/弹出抽屉按钮，桌面端侧栏固定展开；新增移动端布局，手机上通过左上角汉堡按钮打开抽屉侧栏，点击导航项后自动收起，支持电脑与手机浏览器
- **侧边栏「分享」与「系统」分组间去除分隔横线**：两组直接衔接，保留「系统」灰色分类标签作区分提示
- **存储空间信息统一收敛**：存储详情弹窗不再重复展示「系统信息 / 运行信息」，改为统一在 系统管理 → 运行环境 一处展示，并补全了存储类型、存储路径；运行时卡片归并为「系统信息」「运行信息」两块
- **侧边栏存储条去掉右侧箭头**：整行仍可点击进入存储详情，仅移除视觉上的方向指示

### 修复

- **修复「加载传输设置失败」**：`sys_user_transfer_setting` 表缺失 `auto_navigate_transfer` 列导致查询报错。新装库由种子脚本创建正常；升级部署需执行
  `ALTER TABLE sys_user_transfer_setting ADD COLUMN auto_navigate_transfer tinyint NOT NULL DEFAULT '1' COMMENT '任务添加后自动跳转传输页 1开 0关' AFTER chunk_size;`

## 升级注意（行为变更）

- 部署包不含运行数据与机器本地配置；解压后 `bin\start.bat` 首次启动自动初始化数据库与配置
