## 主要变更

### 新功能
- 存储插件体系扩展至 SMB / WebDAV / SFTP / FTP / 本地挂载，并接入目录扫描
- 对外文件服务：内置 WebDAV / SFTP 服务端，管理页并入统一「服务」页
- 新增功能开关页：收藏 / 历史菜单支持全局显隐（默认关闭）
- 预览、编辑统一弹窗化；删除菜单拆分为「移到回收站」与「彻底删除」
- 大文件分片下载接入

### 修复
- 「同时上传数量」设置此前不生效，多文件仍并发上传；现改为任务级 FIFO 排队，设置即时生效，传输列表与上传面板均显示排队状态
- 分享内容接口匿名放开，分享页无需登录即可预览与下载
- 预览流接口补齐防盗链鉴权，覆盖全部静态路径

### 界面优化
- 去掉顶部 Header，主题切换与侧栏折叠并入用户菜单
- 传输列表列宽固定、状态徽章改为低饱和配色，排队任务明确标识

### 升级提示（3.0.0 → 3.1.0）
- 新增 `sys_feature_toggle` 表，需执行 `release/deploy-package/sql/init.sql` 中对应建表语句；其余数据结构向后兼容

## 部署包说明

`gfs-3.1.0-windows-x64.zip` 自带 JDK 21、MySQL 8.4、Redis，目标服务器无需预装任何软件：

1. 解压后运行 `bin\start.bat`（首次运行自动初始化数据库）
2. 浏览器访问 http://localhost
3. 默认账号 `admin` / `admin`

端口、数据库密码、JVM 参数统一在 `bin\env.bat` 修改。
