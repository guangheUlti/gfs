# GFS v5.0.0 发布说明

`gfs-5.0.0-windows-x64.zip`（自带 JDK 21、MySQL 8.4、Redis，免安装部署）

## 主要变更

### 新功能

- **回收站可配置**：设置 → 功能开关新增「回收站」开关。开启时删除文件移入回收站、可还原；关闭时删除直接永久删除（不可恢复）。永久删除独立入口已从文件页右键移除，能力收敛到回收站页面
- **分享可配置**：设置 → 功能开关新增「分享」开关。关闭时文件页右键菜单与批量工具条不出现分享入口；已生成的分享链接访问不受影响
- **功能开关开放给所有用户**：设置 → 功能开关不再仅系统管理员可见，所有登录用户都可查看并切换（开关影响全体用户的日常功能；系统管理等敏感页面仍仅管理员可见）
- **传输页跳转行为细化**：下载任务自动跳转直达「下载中」tab（上传仍直达「上传中」），tab 状态同步进 URL，刷新后停留在原 tab
- **任务完成自动返回**：开启「任务添加后跳转进度页」时，因自动跳转进入传输页、且全部任务完成后自动跳回文件页（恢复离开时目录）；手动切换到传输页不触发
- **admin 种子用户昵称修正**：新装环境左上角用户菜单直接显示 admin（原为 Administrator）

### 修复

- **多文件并发上传不再误报「请求超时」**：大文件并发上传占满带宽与浏览器连接池后，控制面请求排队超时的根因已修——全局 API 超时 10s→30s，init/check/chunks 请求 30s、合并分片 300s；上传执行器加跨任务全局并发上限（在途分片 ≤5，给页面请求留连接余量）；超时/网络错误提示 3 秒去重不再刷屏
- **下载任务自动跳转落错 tab**：修复下载后跳转仍停留在「上传中」tab 的问题

### 界面优化

- **分享弹窗结果界面精简**：移除底部「取消/复制链接」按钮，复制操作分别内联到两条链接右侧（分享页链接 / 复制直链）；分享页链接改为与直链一致的长度自适应布局（超长截断、悬停显示完整内容）；关闭走右上角 X
- **文件页右键菜单精简**：移除「复制直链」重复入口（分享弹窗内已含直链复制）

### 升级注意（行为变更）

- **回收站与分享缺省均为关闭**：从 4.x 升级后，删除文件默认直接永久删除、文件页默认不显示分享入口——需要这两个功能请到 设置 → 功能开关 中开启
- 部署包不含运行数据与机器本地配置；解压后 `bin\start.bat` 首次启动自动初始化数据库与配置
