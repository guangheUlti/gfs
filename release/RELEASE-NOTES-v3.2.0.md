## 主要变更

### 新功能
- **本地存储落盘加密**：新增「文件加密」开关与密钥配置（内置本地存储 / 本地目录挂载均支持），开启后新上传文件以 AES-128-CTR 落盘密文（每文件随机 IV），换密钥后旧密文即不可读；系统内预览、下载、在线播放、WebDAV/SFTP 全路径透明解密，Range 拖动播放按计数器精确定位，实测加解密吞吐 430+ MB/s；开启加密后自动禁用秒传/内容去重，防止密钥更换后复用对象失效
- **存储空间详情弹窗**：点击侧栏底部存储条打开详情，环形使用率仪表（75%/90% 阈值变色）+ 已用/剩余/总量/存储类型统计卡，系统信息（OS / CPU / 负载 / JVM 内存 / Java 版本）与运行信息（启动时间 / 运行时长 / 存储类型 / 存储路径）双栏面板，磁盘分区逐盘用量卡片并高亮当前存储所在盘；新增 `GET /apis/home/system/info` 接口
- **多存储并行启用与切换**：文件页新增存储切换器，多个存储配置可同时启用，切换后清空搜索回到该存储根目录
- 存储配置保护：内置本地存储禁止删除；存储下仍有文件索引时禁止删除，防止文件失联；编辑本地存储根目录提示仅对新上传文件生效

### 修复
- 加密与秒传/去重冲突：加密存储下跳过内容复用（含合并后并发去重），避免换密钥后引用对象不可解
- 内置本地存储配置行返回前端时对密钥等敏感字段打掩码，编辑提交掩码/空白按「不变」回填

### 界面优化
- 视频预览播放框重构：固定 16:9、80% 宽居中，背景跟随主题色（不再纯黑），支持解码失败/编码不支持提示居中展示
- 视频播放器补齐与音频一致的快捷键：空格播放/暂停、←/→ 快退快进 5 秒、Ctrl+←/→ 或 PgUp/PgDn 切换视频
- 音频播放器新增播放模式（顺序 / 单曲 / 单曲循环 / 随机），记忆上次选择
- 文件搜索框输入后显示一键清空按钮，点击清空并恢复全量列表
- 侧栏折叠后的展开按钮移至菜单栏最底部
- 服务页 WebDAV/SFTP 卡片改为大屏一行两张等宽布局
- 传输列表新增上传/下载类型列

### 升级提示（3.1.0 → 3.2.0）
- 数据结构无变更，向后兼容，直接替换部署包升级
- 本地存储 `base-url` 配置项已移除（直链改由系统接口提供），升级后 `conf/application-prod.yml` 无需再配置该项

## 部署包说明

`gfs-3.2.0-windows-x64.zip` 自带 JDK 21、MySQL 8.4、Redis，目标服务器无需预装任何软件：

1. 解压后运行 `bin\start.bat`（首次运行自动初始化数据库）
2. 浏览器访问 http://localhost
3. 默认账号 `admin` / `admin`

端口、数据库密码、JVM 参数统一在 `bin\env.bat` 修改。
