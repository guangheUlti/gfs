## 主要变更

### 新功能
- **WebDAV 支持 HTTP Range 分片下载**：WebDAV 下载接口（`/dav/**` GET）原生支持 `Range` 请求头，返回 `206 Partial Content` 与 `Content-Range`；Android/iOS 及桌面播放器通过挂载 WebDAV 播放视频时可秒开、拖动进度条快速定位、断点续播（不再整段全量拉取）；无效范围正确返回 `416`。本次大版本号升级的主要能力
- **一键复制直链**：文件/文件夹右键菜单新增「复制直链」，选中即生成（自动复用未过期分享，不重复创建）；可分享项受 `file:share` 权限与分享有效期控制
- **批量 ZIP 下载**：多选文件/文件夹后一键打包下载，创建异步下载任务、轮询进度、完成后下载 zip；支持关闭会话/刷新后继续
- **站内搜索体验增强**：关键词高亮显示（不区分大小写）、搜索态提示条、无结果空状态引导，提升搜索定位效率

### 界面优化
- 文件搜索框输入后显示一键清空按钮
- 传输列表新增上传/下载类型列（随 v3.2.0 并入本次发行产物）

### 升级提示（3.2.0 → 4.0.0）
- 数据结构无变更，向后兼容，直接替换部署包升级
- 本次发行同步补齐此前批次功能（批量 ZIP 下载、一键复制直链、站内搜索体验增强）的部署包产物

## 部署包说明

`gfs-4.0.0-windows-x64.zip` 自带 JDK 21、MySQL 8.4、Redis，目标服务器无需预装任何软件：

1. 解压后运行 `bin\start.bat`（首次运行自动初始化数据库）
2. 浏览器访问 http://localhost
3. 默认账号 `admin` / `admin`

端口、数据库密码、JVM 参数统一在 `bin\env.bat` 修改。
