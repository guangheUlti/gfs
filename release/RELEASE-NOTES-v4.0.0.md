# GFS v4.0.0 发布说明

`gfs-4.0.0-windows-x64.zip`（自带 JDK 21、MySQL 8.4、Redis，免安装部署）

## 主要变更

### 新功能

- **WebDAV 服务**：新增原生 WebDAV 端点（`/dav/**`），可使用任意 WebDAV 客户端将网盘挂载为本地磁盘。支持 BASIC 认证（使用 GFS 系统账号密码）、目录浏览（PROPFIND）、在线新建/编辑（MKCOL/PUT/MOVE/COPY/DELETE）。挂载后即可像本地目录一样浏览、拖拽、重命名、删除，并可被邮件、编辑器等第三方软件直接读写
  - **HTTP Range 分片下载**：下载原生支持 `Range` 请求头，返回 `206 Partial Content` 与 `Content-Range`，无效范围正确返回 `416`。Android/iOS 及桌面播放器通过挂载 WebDAV 播放视频时可秒开、拖动进度条快速定位、断点续播，不再整段全量拉取
  - **在线编辑锁（LOCK/UNLOCK）**：支持 Office 等客户端在线编辑所需的文件锁协议，防止多人同时写同一文件冲突；被他人锁定的文件在写入/删除/移动/复制时返回 `423 Locked`
- **JVM 内存可配置 + 一键重启**：在 **设置 → 系统 → 系统管理** 中可在线修改 JVM 最大堆内存（256～65536 MB），点击「重启服务」即自动应用生效，重启过程由后台看门狗守护，无需人工操作服务器；重启期间显示进度遮罩（虚拟进度 + 存活探测），服务恢复后提示成功并自动刷新页面数据
- **系统状态卡片**：存储空间弹窗与系统管理页展示操作系统**物理内存总量 / 已用 / 可用**，帮助运维直观评估资源水位
- **一键复制直链（永久有效）**：文件/文件夹右键菜单新增「复制直链」，生成即永久有效、免登录即可下载；自动复用未过期分享，不重复创建
- **批量 ZIP 下载**：多选文件/文件夹后一键打包下载，创建异步下载任务、轮询进度、完成后下载 zip；支持关闭会话/刷新后继续
- **站内搜索体验增强**：关键词高亮显示（不区分大小写）、搜索态提示条、无结果空状态引导
- **SMB 存储增强**：使用 smbj 库优化 SMB 连接与目录操作，支持匿名访问，挂载点展示名称可自定义（优先显示自定义挂载名，其次共享名）
- **大文件下载支持任意大小**：超过浏览器缓存能力的大文件自动改走服务端流式直下（浏览器原生下载，无大小上限）；HTTPS 环境仍走分片落盘 + 断点续传
- **文件页位置记忆**：从文件页切到传输页查看进度后再返回，自动恢复离开时的目录位置，列表快照秒开无加载闪烁；登出自动清空

### 修复

- **修复 http 部署下载文件报「无法创建本地下载缓存」**：本地下载缓存（OPFS）仅在 HTTPS 或 localhost 下可用，HTTP 部署时 ≤512MB 文件自动降级内存模式，更大文件走服务端流式直下，下载功能在 HTTP 部署下完全可用
- **修复外部 frontend 目录热更新不生效**：静态资源处理此前硬编码内嵌路径，覆盖了部署包配置的外部 `frontend/` 覆盖层；现已透传 `spring.web.resources.static-locations`，替换前端产物无需重打 JAR
- **内存降级模式续传安全**：降级模式下丢弃旧的分片进度整体重下，避免拼出含空洞的损坏文件

### 界面优化

- **设置界面改版**：设置项以「系统」分组集中管理，「系统管理」页承载 JVM 配置与服务重启；功能开关（如收藏功能）关闭后，文件工具栏及右键菜单中对应入口自动隐藏
- **分享对话框溢出修复**：修复直链过长导致右侧按钮被挤出/出现横向滚动条的问题，直链超长时以省略号截断并悬浮显示完整路径
- **分享列表 / 回收站**：支持按住拖拽框选（橡皮筋多选），与文件列表交互一致
- **存储路径绝对化**：磁盘分区卡的存储路径显示为解析后的绝对路径
- **文件搜索框**：输入后显示一键清空按钮
- **传输列表**：新增上传/下载类型列

### 升级提示（3.2.0 → 4.0.0）

- 数据结构无变更，向后兼容，直接替换部署包升级
- 若需启用 WebDAV 在线编辑锁，请确保服务以**看门狗模式**启动（`bin\start.bat run-watchdog`），使「重启服务」与 JVM 配置变更能自动生效

## 部署包说明

发行包不含任何运行数据与机器本地配置（MySQL/Redis 数据、日志、生成的配置文件均不打入 zip），解压即干净的初始状态。

1. 解压后运行 `bin\start.bat`（首次运行自动初始化数据库；如需看门狗模式运行 `bin\start.bat run-watchdog`）
2. 浏览器访问 http://localhost
3. 默认账号 `admin` / `admin`

端口、数据库密码、JVM 参数统一在 `bin\env.bat` 修改；JVM 最大堆内存也可在 **设置 → 系统 → 系统管理** 页面在线调整并重启生效。
