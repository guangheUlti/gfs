## 主要变更

### 破坏性变更
- 移除工作空间、自定义角色、权限配置、成员邀请整套多用户协作体系，权限简化为内置用户权限
- 数据库初始化脚本已重写，未提供 2.x → 3.0 迁移脚本，老版本数据需手动处理

### 新功能
- 文本文件创建与在线编辑
- 文件框选
- 操作系统文件拖入上传
- 存储容量查询

### 界面优化
- 文件页「全选 / 统计 / 视图切换」一行移至底部状态栏，更接近资源管理器布局
- 批量操作栏与拖拽提示避开状态栏

## 部署包说明

`gfs-3.0.0-windows-x64.zip` 自带 JDK 21、MySQL 8.4、Redis，目标服务器无需预装任何软件：

1. 解压后运行 `bin\start.bat`（首次运行自动初始化数据库）
2. 浏览器访问 http://localhost
3. 默认账号 `admin` / `admin`

端口、数据库密码、JVM 参数统一在 `bin\env.bat` 修改。
